Weekly Coding Practice Tracker

Objective : Create a Java program to track coding practice for 7 days using a 'while' loop and hard-coded values.

Requirements
- Store daily:
  - Problems Attempted
  - Problems Solved
  - Practice Hours
  - A day is productive if:
  - Solved >= 5
  - Practice Hours >= 2
- Weekly target: 35 solved problems.

Output
- Total Problems Attempted
- Total Problems Solved
- Success Percentage
- Total Practice Hours
- Average Problems Solved
- Productive Days
- Non-Productive Days
- Weekly Target Status
- Consistency Status

Concepts Used
- while loop
- if-else
- Arithmetic operators
- Logical operators
- Ternary operator
- Type casting
